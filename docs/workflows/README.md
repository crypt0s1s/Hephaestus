# Workflows

Workflows describe repeatable collaboration processes for building Hephaestus.

- [Feature Creation And Development Flow](./feature-creation-and-development-flow.md): PRD-first process for defining, designing, implementing, and validating feature work.
- [Running Tests](./running-tests.md): validation commands for lint, build, unit tests, and macOS UI tests.
- [Subagent Implementation Review Loop](./subagent-implementation-review-loop.md): orchestrated implementation and review workflow using separate implementer and reviewer agents.
